# 现场测量许可申请信（模板）

> 用法：把【】里的内容替换掉，打印后盖章/签名，交给建筑管理方或文保部门。若对方需要正式公函，可请学院/实验室出具抬头纸。

**关于非破坏性楼梯磨损测量与短期人流计数的申请**

尊敬的【建筑管理单位 / 文保部门】：

我是【学校/单位】【学院/系】的【姓名】，【身份：本科生/研究生/教师】，研究方向为【文化遗产数字化/土木工程/数学建模】。我们正在开展一项关于“历史建筑楼梯磨损与使用史”的研究，希望申请对【建筑名称】内的【3】座楼梯进行非破坏性测量和短期人流计数。

**研究目的**

通过摄影测量获取踏步表面的三维几何，结合材料硬度和人流记录，研究磨损剖面能在多大程度上反映楼梯的使用频率、方向偏好和并排通行方式。研究结果用于方法学论文和遗产保护建议，不涉及任何商业用途。

**测量内容与方式**

1. 每座楼梯选择 5 级连续踏步，每级拍摄 40–80 张照片，使用打印的比例尺和编码标记点进行三维重建。
2. 使用回弹仪/里氏硬度计在非显眼位置测量材料硬度（每级 5 个点，不取样、不钻孔）。
3. 在【14】天内进行人流计数：每天 3 个 30 分钟时段，分上行/下行计数；如贵单位已有门禁/闸机计数，我们希望申请导出同期汇总数据（不需个人信息）。
4. 不进行任何破坏性取样、不清洁表面、不移动构件；不记录任何个人身份信息；照片中避免可识别人脸。

**时间与人员**

现场测量【2–3】次，每次【1–2】小时，由【2–3】名研究人员完成；人流计数由我方人员完成，不干扰正常通行。预计在【日期】至【日期】之间完成。

**数据使用与回馈**

测量数据仅用于学术研究，建筑名称和位置在论文中可匿名化处理（按贵单位要求）。分析完成后，我们可向贵单位提供一份简要报告（磨损分布、重点保护建议），并在论文致谢中注明贵单位的支持。

**申请事项**

1. 允许我们在上述楼梯进行非破坏性摄影测量和硬度测试；
2. 允许我们在【14】天内进行人流计数；
3. 如方便，提供楼梯的建造/安装年份、修缮记录，以及同期门禁/售票计数汇总。

随信附上测量协议、比例尺样张和示例照片。如需进一步说明，请随时联系我。

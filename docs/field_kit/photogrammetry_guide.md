# 手机摄影测量现场指南

目标：每座楼梯 5 级踏步，每级拍 40–80 张照片，后期重建为带尺度的三维模型。总现场时间约 10–15 分钟/楼梯。

## 1. 带什么

- 智能手机（1200 万像素以上；关闭美颜/广角畸变修正）
- 打印好的 `scale_bar_A4.pdf`（**100% 打印**，现场用直尺核对 100 mm）
- 4 个编码标记点（可用打印纸 + 胶带固定，不要贴在文物表面留胶）
- 软毛刷（只扫浮尘，不清洁、不用水）
- 卷尺/直尺（记录踏步高、踏面深）
- 记录表/手机备忘录（楼梯编号、日期、光照、异常）

## 2. 拍摄前

1. 把比例尺平放在踏面上，至少两个，互相垂直；棋盘格放在一侧。
2. 用直尺核对比例尺的 100 mm 刻度；误差 >1 mm 就重新打印。
3. 记录：踏步高、踏面深、前缘半径、材料、表面是否抛光、是否有水/沙。
4. 光线：阴天或室内漫射光最好；避免正午直射和强反光。大理石/抛光石材尤其容易过曝。

## 3. 拍摄

- 距离踏面 30–50 cm；不要用超广角，不要变焦。
- 锁定对焦和曝光；关闭 HDR、闪光灯、美颜。
- 三圈拍摄：
  1. **俯拍圈**：从踏面前缘到后缘，覆盖全宽，70% 重叠；
  2. **斜拍圈**：与踏面成 30–45°，覆盖前缘和凹陷；
  3. **侧拍圈**：从左右两侧各拍一组，覆盖立板和边缘。
- 每圈 15–30 张；总共 40–80 张/踏步。
- 每张都要包含至少一个比例尺或标记点；不要裁掉。
- 走位要慢，避免运动模糊；每张停 0.5 秒。

## 4. 导出

任选一种：

- **Polycam**（手机）：拍照/扫描后导出 **OBJ + MTL + 纹理** 或 **PLY**。
- **RealityCapture**（PC，教育/非商业免费）：导入照片，对齐、重建、导出 OBJ/PLY。
- **Agisoft Metashape**（30 天试用）：Align Photos → Build Dense Cloud → Build Mesh → Export OBJ/PLY。
- **COLMAP**（开源，需要 PC）：适合有经验者；我可以提供命令。

导出要求：

- 带真实尺度（或在场景中保留比例尺，后期用 100 mm 定标）；
- 点云/网格不要过度简化；保留纹理；
- 每座楼梯一个文件夹，命名 `C1/`、`C2/`、`A1/`…；
- 每级踏步一个子文件夹 `tread01/`…`tread05/`。

## 5. 上传/交付

把压缩包放到：

```
q1_rebuild/data/field/raw/<stair_id>.zip
```

或直接告诉我文件夹路径。附一个 `notes.txt`：楼梯编号、日期、拍摄人、光照、任何异常。

## 6. 常见错误（会直接导致重建失败）

- 比例尺没拍进去，或打印时被“适合页面”缩放。
- 照片重叠不足（<60%），或走位太快导致模糊。
- 抛光石材反光过曝；用偏振片/侧光/漫射布改善。
- 只拍踏面，不拍立板和边缘；参考面无法重建。
- 不同光照/不同日期混在一组；尽量同一次拍完。

- 切 5 级踏步、提取横向剖面；

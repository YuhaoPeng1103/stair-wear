# 楼梯磨损数据采集 SOP（标定 + 应用）

**目标**：为“用磨损剖面反演使用史”这篇 Q1 论文采集两类真实数据：

- **标定楼梯（calibration stairs）**：已知累计人流 \(N\)，用来标定 \(\kappa=k/H\)。
- **应用楼梯（application stairs）**：历史建筑楼梯，未知人流，用来展示反演与不确定性。

最小可发表数据集：**3 座标定楼梯 + 3 座应用楼梯**。每座楼梯测 **5 级踏步**，每级 **3 条纵向剖面 + 1 条横向剖面**。标定楼梯需 **14 天**人流计数。

> 关键：没有标定楼梯，论文只能停在“模拟研究”；有了 2–3 座，就能把“不可识别”变成“可识别”，这是全文的贡献点。

---

## 1. 标定楼梯的选择标准

优先顺序：

1. **有门禁/闸机/售票计数**的公共建筑楼梯（图书馆、办公楼、博物馆、教学楼、宿舍）。
2. **安装年代明确**（≥5 年），期间未更换踏步面层、未做整体翻新。
3. **材料均一**（石材、水磨石、混凝土、木材），表面无涂层或涂层已知。
4. **人流可分流计数**（至少能区分上行/下行，或能估计方向比例）。
5. **非破坏测量许可**容易获得。

建议组合（覆盖不同材料/硬度）：

| 编号 | 类型 | 材料 | 已知信息 |
|---|---|---|---|
| C1 | 图书馆/教学楼 | 花岗岩或水磨石 | 安装年份、门禁计数 |
| C2 | 办公楼/宿舍 | 大理石或瓷砖 | 安装年份、入住人数 |
| C3 | 博物馆/车站 | 石材 | 售票/闸机计数 |

排除：刚翻新（<2 年）的楼梯；有地毯/防滑条覆盖的楼梯；人流统计缺失或严重不完整的楼梯。

## 2. 人流计数

### 2.1 自动计数
- 闸机/门禁导出：按日汇总，保留小时数据。
- 若计数器只覆盖建筑入口，需估计使用该楼梯的比例 \(p\)：在 3 个时段（早高峰、午间、晚高峰）各人工计数 30 分钟，校准 \(p\)。

### 2.2 人工计数（无自动计数时）
- 连续 14 天，每天 3 个 30 分钟时段（如 8:00–8:30、12:00–12:30、17:30–18:00）。
- 同时记录上行/下行。
- 用时段权重外推到全天；周末/工作日分开。
- 记录闭馆、假期、施工等异常日。

### 2.3 累计人流
\[
N = \bar n_{\text{day}} \times D_{\text{service}} \times p
\]
其中 \(\bar n_{\text{day}}\) 是日均计数，\(D_{\text{service}}\) 是自安装以来的使用天数，\(p\) 是该楼梯的使用比例。

**不确定度**：计数器误差 ±2%，抽样误差按 14 天日计数的标准误，\(p\) 的误差按人工计数比例估计。三者合成写入 `metadata.csv` 的 `N_rel_sd`。

## 3. 几何测量

### 3.1 方法 A：摄影测量（低成本，推荐）
- 每级踏步 40–80 张重叠照片，覆盖踏面、立板、边缘；避免强反光。
- 放置**比例尺**（至少 2 把，互相垂直）和 4–6 个编码标记点。
- 用 Agisoft Metashape / RealityCapture / COLMAP 重建。
- 输出：带尺度的稠密点云（`.ply`）或网格（`.obj`）。
- 典型精度：0.5–2 mm（取决于纹理、光照、拍摄距离）；必须用重复测量验证，不能假设。

### 3.2 方法 B：结构光/激光扫描（高精度）
- 手持或三脚架扫描仪，点间距 ≤1 mm。
- 每级至少 2 站，重叠 ≥30%。
- 典型精度：0.1–0.5 mm。

### 3.3 方法 C：手工剖面规（兜底）
- 用 profile gauge / 深度尺沿 3 条纵向线测量，间隔 10 mm。
- 精度约 1 mm；只适合作为补充或预调查。

### 3.4 测点布置
每座楼梯选 **5 级连续踏步**（避开最上/最下一级，减少边界效应）。每级：

- 纵向剖面 3 条：距左侧边缘 50 mm、中心线、距右侧边缘 50 mm；每条从踏面前缘（nosing）到后缘，间隔 5–10 mm。
- 横向剖面 1 条：踏面进深中点，横跨全宽，间隔 5–10 mm。
- 记录：踏步高、踏面深、前缘半径、材料、表面处理。

### 3.5 尺度与配准检查
- 用踏步高（或已知标尺）检查尺度：相对误差应 <0.5%。
- 同一级重复扫描 3 次，配准后剖面差的 SD 应 <0.3 mm；否则该级作废。
- 记录配准 RMSE。

## 4. 参考面（未磨损面）重建

这是审稿人最关注的步骤。优先级：

1. **未磨损边缘/前缘**：踏步前缘通常磨损最轻，用其拟合原始平面。
2. **同批未使用踏步**：同一楼梯间被封堵/不常使用的踏步。
3. **几何先验**：原始踏面应为平面；用外侧 20% 未磨损区域拟合平面，再外推到中心。
4. **同建筑同期楼梯**：作为对照。

在论文中必须报告：用了哪种参考面、拟合残差、以及参考面不确定性对 \(N\) 的影响。

---

## 5. 材料参数

- 硬度：Leeb 硬度计或 Schmidt 回弹仪，每级 5 点，取中位数；记录湿度/表面状态。
- 密度/孔隙率：如能取到同批石材样品（非破坏或既有样品），送实验室测。
- 磨损系数 \(k\)：不要直接假设；通过标定楼梯反算 \(\kappa=k/H\)。文献值只作为先验。

## 6. 元数据表（`metadata.csv`）

| 字段 | 说明 |
|---|---|
| `stair_id` | 唯一编号，如 `C1`、`A1` |
| `site` | 建筑/地点（论文中可匿名） |
| `role` | `calibration` 或 `application` |
| `install_year` | 安装/建造年份 |
| `service_days` | 累计使用天数 |
| `mean_daily_footfall` | 日均人流 |
| `footfall_rel_sd` | 人流相对不确定度 |
| `material` | 石材/木材/水磨石等 |
| `hardness_leeb` | 硬度中位数 |
| `hardness_sd` | 硬度标准差 |
| `indoor` | 1/0 |
| `renovation` | 翻新记录（无则 `none`） |
| `scan_method` | `photogrammetry` / `laser` / `profile_gauge` |
| `scan_accuracy_mm` | 重复测量 SD |
| `reference_method` | 参考面重建方法 |
| `notes` | 许可、异常、缺失 |

## 7. 剖面表（`profiles.csv`）

| 字段 | 说明 |
|---|---|
| `stair_id` | 对应 `metadata.csv` |
| `tread_index` | 踏步编号（1–5） |
| `profile_id` | 纵向 `L1–L3`，横向 `T1` |
| `x_mm` | 横向坐标（以踏步中心为 0） |
| `y_mm` | 进深坐标（以前缘为 0） |
| `z_mm` | 相对参考面的高度（磨损深度为负） |
| `h_mm` | 磨损深度 = 参考面 − 实测面 |
| `valid` | 1/0（剔除异常点） |

## 8. 质量控清单

- [ ] 每座楼梯 ≥5 级、每级 ≥3 条纵向剖面
- [ ] 比例尺/尺度检查通过（<0.5%）
- [ ] 重复测量 SD <0.3 mm
- [ ] 参考面拟合残差 <0.5 mm
- [ ] 人流计数 ≥14 天，含工作日/周末
- [ ] 安装年份有书面依据（合同、碑刻、物业记录）
- [ ] 现场许可与数据使用许可
- [ ] 原始点云/照片存档，附 DOI（Zenodo/Figshare）

---

## 9. 伦理与许可

- 进入建筑、拍摄、扫描需书面许可；历史建筑需文保部门同意。
- 不进行任何破坏性取样；硬度测试选不显眼位置。
- 人流计数不记录个人身份信息；照片中避免可识别人脸。
- 数据发布前与产权方确认匿名化要求。

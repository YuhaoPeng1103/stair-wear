# Stair-wear identifiability and calibration

Code and synthetic data for the manuscript:

> Peng, Y. (2026). *What worn stair treads can and cannot tell: identifiability, calibration, and measurement design for wear-based inspection of historic stairs.* Manuscript under review.

The study asks what a worn stair profile can identify. In an Archard-type wear
model the number of footfalls `N` and the wear coefficient `kappa` enter only
through their product, so a profile constrains `kappa*N` but not `N`. The code
reproduces the identifiability analysis, the calibration design, the synthetic
experiments, the sensitivity analysis, and the public-model stress test.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Main simulation study (writes results/)
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python experiments/run_simulation.py

# Figures 1-8
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python experiments/make_figures.py

# Sensitivity analysis and Figure 9
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python experiments/sensitivity.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python experiments/make_sensitivity_figure.py

# Literature anchor (Borobudur)
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python experiments/literature_anchor.py
```

Runtime is about 5-10 minutes on a laptop.

## Data and models

- **No field data were collected.** All tabular results are synthetic and are
  regenerated by the code; random seeds are fixed.
- **Public 3D models** are not redistributed. Download links and CC BY 4.0
  attribution are in `data/public_model/README.md` and `NOTICE`. The derived
  profiles and the Section 3.4 stress test are generated locally by
  `experiments/extract_public_profiles.py` and `experiments/public_model_case.py`.
- The synthetic field-format demo in `data/field_demo/` is a pipeline test, not
  measured data.

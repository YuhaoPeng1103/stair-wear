Put the downloaded Sketchfab model here. I will handle the rest.

## How

1. Open the model page while logged in.
2. Click **Download 3D Model**.
3. Choose **glTF** (`.glb`) if offered; otherwise the original/OBJ/PLY archive.
4. Save the file (or the `.zip`) into this folder, keeping the original name.
5. Tell me the filename (or just say "done").

Do not rename the file to something ambiguous; the original name helps me check the licence and attribution.
